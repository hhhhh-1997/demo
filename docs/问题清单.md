## 附：交互过程中的默认决定（未单独提问，可在评审时推翻）

1. 维护模块统计卡片按需求文档 4 项（总数/草稿/论证退回/审核退回），而非原型图的「已提报」。
2. 储备库图表数据按真实数据聚合，原型图是硬编码假数据。
3. 原型图顶栏「全局搜索框 + 通知铃铛」无需求文档支撑，按 UI 占位处理（仅保留主题切换 + 用户下拉/退出）。
4. 图标用 Element Plus 图标映射（`fa-paper-plane→Promotion`、`fa-eye→View` 等），不额外引入 Font Awesome。
5. 论证/审核记录存 `project_review` / `project_audit` 两张流程记录表（含历史），项目状态作为唯一事实源。
6. 论证通过率 = 通过数 ÷（通过数 + 退回数）；审核通过率同口径（均不含待处理项）。
