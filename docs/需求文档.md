## 1. 概述

### 1.1 系统名称

综合计划储备项目管理

### 1.2 系统目标

对综合计划类储备项目进行全生命周期管理，涵盖项目创建维护、论证检查、审核审批、统一储备库下达四大环节，实现储备项目的规范化、流程化管控。

### 1.3 模块组成

| 编号 | 模块名称 | 功能定位 |
|------|---------|---------|
| M01 | 储备项目维护 | 项目基础数据录入、编辑、删除与提报管理 |
| M02 | 储备项目论证 | 项目合规性与可行性检查论证 |
| M03 | 储备项目审核 | 论证结果的人工复核与审批 |
| M04 | 统一储备库 | 审核通过项目的统一管理与下达 |

### 1.4 流程状态定义

系统项目共包含 **7 种状态**：

| 状态 | 说明 | 所属环节 |
|------|------|---------|
| 草稿 | 新建未提报的项目 | 维护 |
| 待论证 | 维护提报后，等待论证 | 论证 |
| 论证退回 | 论证不通过，退回维护 | 维护 |
| 待审核 | 论证通过，等待审核 | 审核 |
| 审核退回 | 审核不通过，退回维护 | 维护 |
| 待下达 | 审核通过，进入储备库，等待下达 | 统一储备库 |
| 已下达 | 已下达执行 | 统一储备库 |

### 2.2 模块数据范围

| 模块 | 展示状态 | 可操作状态 | 其他状态 |

> 注：「论证通过」指论证已通过、当前状态为「待审核」的项目；「审核通过」指审核已通过、当前状态为「待下达」的项目，在源模块中展示为只读记录。

## 3. 储备项目维护

### 3.1 功能描述

提供储备项目基础信息的全流程维护功能。模块展示**所有状态**的项目信息；其中「草稿」「论证退回」「审核退回」状态的项目支持编辑与提报操作，「草稿」状态额外支持删除，其余状态的项目仅可查看。

### 3.2 统计卡片

| 指标 | 说明 |
|------|------|
| 项目总数 | 当前所有状态项目的总数量 |
| 草稿 | 状态为「草稿」的项目数 |
| 论证退回 | 状态为「论证退回」的项目数 |
| 审核退回 | 状态为「审核退回」的项目数 |

统计数随数据变更实时更新。

### 3.3 筛选区

| 筛选项 | 控件类型 | 选项 |
|--------|---------|------|
| 二级分类 | 下拉选择 | 电网基建 / 生产设备技改 / 科技创新 / 营销投入 / 信息化建设 |
| 所属单位 | 下拉选择 | 省公司本部 / 成都供电公司 / 绵阳供电公司 / 德阳供电公司 |
| 状态 | 下拉选择 | 全部 / 草稿 / 待论证 / 论证退回 / 待审核 / 审核退回 / 待下达 / 已下达 |
| 搜索 | 文本输入 | 按项目名称模糊匹配 |

筛选条件变更时自动刷新列表并重置至第 1 页。

### 3.4 数据表格

| 列名 | 说明 | 对齐 |
|------|------|------|
| 复选框 | 仅草稿/论证退回/审核退回行显示，用于批量提报 | 居中 |
| 序号 | 分页内序号 | 左对齐 |
| 项目名称 | 项目文本名称 | 左对齐 |
| 二级分类 | 标签显示（badge-primary） | 左对齐 |
| 投资金额（万元） | 千位分隔格式 | 右对齐 |
| 所属单位 | 单位名称 | 左对齐 |
| 状态 | 状态标签（颜色见状态流转规则） | 左对齐 |
| 创建时间 | `YYYY-MM-DD HH:MM` 格式 | 左对齐 |
| 操作 | 提报/编辑/删除按钮（按状态显示） | 左对齐 |

### 3.5 操作按钮

| 操作 | 可见条件 | 行为 |
|------|---------|------|
| 新增项目（顶部按钮） | 始终可见 | 打开空白新增弹窗 |
| 提报（行按钮） | 草稿/论证退回/审核退回 | 弹出确认框，确认后状态变为「待论证」 |
| 编辑（行按钮） | 草稿/论证退回/审核退回 | 打开编辑弹窗，预填当前数据 |
| 删除（行按钮） | 仅草稿状态 | 弹出确认框，确认后从列表中移除 |
| 批量提报（表头按钮） | 始终可见 | 勾选草稿/论证退回/审核退回项目，确认后批量变为「待论证」 |
| 导出（表头按钮） | 始终可见 | 将当前筛选结果导出为 CSV 文件 |

### 3.6 新增/编辑弹窗

| 字段 | 控件 | 校验规则 |
|------|------|---------|
| 项目名称 | 单行文本 | 必填 |
| 二级分类 | 下拉选择 | 必选 |
| 投资金额（万元） | 数字输入 | 必填，需大于 0 |
| 所属单位 | 下拉选择 | 必选 |
| 项目描述 | 多行文本 | 选填 |

### 3.7 权限控制

- 草稿/论证退回/审核退回项目：可编辑、提报，行复选框显示；草稿额外可删除
- 待论证/待审核/待下达/已下达项目：操作按钮置灰不可操作，行复选框不显示，仅可查看

### 3.8 业务规则

- 新增项目默认为「草稿」状态
- 草稿/论证退回/审核退回项目提报后状态变更为「待论证」
- 论证退回项目经修改后可重新提报，再次进入论证环节
- 审核退回项目经修改后可重新提报，再次进入论证环节
- 仅草稿状态项目可删除
- 待论证及之后状态的项目不可回退为草稿

## 4. 储备项目论证

### 4.1 功能描述

对提报的储备项目开展储备监督检查，逐项核查项目的合规性和可行性。模块展示「待论证」「论证通过」「论证退回」三类数据，其中「待论证」项目可执行论证，其余状态仅可查看。

### 4.2 统计卡片

| 指标 | 说明 |
|------|------|
| 待论证 | 状态为「待论证」的项目数 |
| 论证通过 | 论证已通过、当前处于「待审核」阶段的项目数 |
| 论证退回 | 状态为「论证退回」的项目数 |
| 论证通过率 | 论证通过数量 / 总论证数量 × 100% |

### 4.3 筛选区

| 筛选项 | 控件类型 | 选项 |
|--------|---------|------|
| 项目名称 | 文本输入 | 模糊匹配 |
| 二级分类 | 下拉选择 | 电网基建 / 生产设备技改 / 固定资产零购 |
| 论证状态 | 下拉选择 | 全部 / 待论证 / 论证通过 / 论证退回 |

### 4.4 数据表格

| 列名 | 说明 |
|------|------|
| 项目编码 | 唯一标识（如 XM202401001） |
| 项目名称 | 项目文本名称 |
| 信息完整性 | 完整=绿色 / 不完整=黄色 |
| 三重一大 | 符合=绿色 / 不符合=红色 |
| 拆分立项 | 无=绿色 / 存在=红色 |
| 界面混淆 | 无=绿色 / 存在=红色 |
| 论证状态 | 待论证=蓝色 / 论证通过=绿色 / 论证退回=红色 |
| 操作 | 论证按钮（仅待论证）/ 查看详情 |

### 4.5 论证检查项

在论证弹窗中提供四个检查维度：

| 检查项 | 选项 | 说明 |
|--------|------|------|
| 信息完整性 | 完整 / 不完整 | 项目申请材料是否齐全 |
| 三重一大 | 符合 / 不符合 | 是否满足三重一大决策要求 |
| 拆分立项 | 无 / 存在 | 是否存在规避审批的拆分立项 |
| 界面混淆 | 无 / 存在 | 是否存在专业界面混淆问题 |

每项检查均以单选方式给出结论，并填写论证意见和最终论证结果（通过/不通过）。

### 4.6 论证规则

- 仅「待论证」项目可执行论证操作
- 论证通过：状态变更为「待审核」，进入审核环节
- 论证不通过：状态变更为「论证退回」，退回维护模块，可修改后重新提报
- 「论证通过」「论证退回」项目仅可查看

## 5. 储备项目审核

### 5.1 功能描述

对论证完成的储备项目进行人工复核，确认论证结果的准确性，决定通过审核或退回。模块展示「待审核」「审核通过」「审核退回」三类数据，其中「待审核」项目可执行审核，其余状态仅可查看。

### 5.2 统计卡片

| 指标 | 说明 |
|------|------|
| 待审核 | 状态为「待审核」的项目数 |
| 审核通过 | 审核已通过、当前处于「待下达」阶段的项目数 |
| 审核退回 | 状态为「审核退回」的项目数 |
| 审核通过率 | 审核通过数量 / 总审核数量 × 100% |

### 5.3 筛选区

| 筛选项 | 控件类型 | 选项 |
|--------|---------|------|
| 项目名称 | 文本输入 | 模糊匹配 |
| 二级分类 | 下拉选择 | 电网基建 / 生产设备技改 / 固定资产零购 |
| 审核状态 | 下拉选择 | 全部 / 待审核 / 审核通过 / 审核退回 |

### 5.4 数据表格

| 列名 | 说明 |
|------|------|
| 复选框 | 用于批量审核选择（仅待审核行） |
| 项目编码 | 唯一标识 |
| 项目名称 | 项目文本名称 |
| 二级分类 | 标签显示（badge-primary） |
| 投资金额（万元） | 千位分隔，右对齐 |
| 论证结果 | 通过=绿色 / 不通过=红色 |
| 审核状态 | 待审核=黄色 / 审核通过=绿色 / 审核退回=红色 |
| 操作 | 审核按钮（仅待审核）/ 查看详情 |

### 5.5 审核操作

| 操作 | 可见条件 | 行为 |
|------|---------|------|
| 审核（行按钮） | 仅待审核状态 | 打开审核弹窗，填写审核意见和审核结果 |
| 批量通过（表头按钮） | 始终可见 | 勾选待审核项目后一键通过 |
| 批量退回（表头按钮） | 始终可见 | 勾选待审核项目后一键退回 |

### 5.6 审核弹窗

- 展示项目基本信息及论证结果，不可编辑
- 提供审核意见文本框
- 提供审核结果下拉（通过/退回）
- 通过或退回后记录审核时间

### 5.7 审核规则

- 仅「待审核」项目可执行审核操作
- 审核通过：状态变更为「待下达」，进入统一储备库
- 审核不通过：状态变更为「审核退回」，退回维护模块，可修改后重新提报
- 「审核通过」「审核退回」项目仅可查看

## 6. 统一储备库

### 6.4 筛选区

- 下达后状态变更为「已下达」，并记录下达时间
- 「已下达」项目仅可查看

## 7. 通用功能规范

### 7.1 分页

所有模块的数据表格均启用分页功能：

| 配置项 | 值 |
|--------|-----|
| 默认每页条数 | 5 条 |
| 位置 | 表格下方 |
| 信息显示 | 左侧：共 N 条，显示第 M-N 条 |
| 翻页控件 | 右侧：上一页 / 页码 / 下一页 |
| 页码策略 | ≤7 页全显示；>7 页时智能省略号（首尾必显示，当前页±1 显示） |
| 筛选联动 | 筛选条件变更自动回到第 1 页 |
| 操作联动 | 新增/编辑/删除/提报/论证/审核/下达后自动回到第 1 页 |

### 7.2 弹窗

所有模块统一使用公共弹窗函数：

| 属性 | 说明 |
|------|------|
| 遮罩层 | 半透明黑色背景 + 毛玻璃效果 |
| 动画 | 淡入淡出 + 缩放过渡 |
| 关闭方式 | 点击遮罩、点击关闭按钮、点击取消按钮 |
| 只读弹窗 | 仅提供「关闭」按钮，无保存操作 |
| 确认保存 | 点击保存按钮触发保存，弹出保存成功提示 |

### 7.3 确认弹窗

用于删除、提报、下达等不可逆操作的二次确认：

- 展示操作标题和提示信息
- 提供取消和确认两个操作按钮
- 确认按钮颜色随操作类型变化（删除=红色、提报=绿色、下达=绿色）

### 7.4 筛选功能

- 标签与输入框同行水平排列
- 筛选条件变更即时生效（无需点击查询按钮）
- 多条件组合筛选（AND 逻辑）
- 筛选区与数据表格分卡片展示，中间以空行分隔

### 7.5 数据导出

- 导出格式：CSV（UTF-8 BOM，兼容 Excel 中文显示）
- 导出范围：当前筛选结果
- 文件命名：`<模块名>_<日期>.csv`

### 7.6 空数据状态

当筛选结果或数据列表为空时，显示空状态占位图标及提示文字「暂无匹配的数据」。

### 7.7 换肤功能

- 提供暗色 / 浅色两种皮肤
- 顶栏提供换肤按钮，点击即时切换
- 切换后主框架与子页面实时联动
- 主题偏好持久化存储，刷新不丢失

## 8. 业务流程

### 8.1 全生命周期流程

```
维护模块：草稿 / 论证退回 / 审核退回
     │  提报
     ▼
  待论证 ──论证通过──▶ 待审核 ──审核通过──▶ 待下达 ──下达──▶ 已下达
     │                    │
     └─论证不通过─▶ 论证退回  └─审核不通过─▶ 审核退回
             │                    │
             └──────── 退回维护模块，修改后可重新提报 ────────┘
```

### 8.2 状态流转规则

| 当前状态 | 所属模块 | 可执行操作 | 目标状态 |
|---------|---------|-----------|---------|
| 草稿 | 维护 | 编辑 / 删除 / 提报 | 草稿（更新）/ 移除 / 待论证 |
| 论证退回 | 维护 | 编辑 / 提报 | 待论证 |
| 审核退回 | 维护 | 编辑 / 提报 | 待论证 |
| 待论证 | 论证 | 论证通过 | 待审核 |
| 待论证 | 论证 | 论证不通过 | 论证退回 |
| 待审核 | 审核 | 审核通过 | 待下达 |
| 待审核 | 审核 | 审核不通过 | 审核退回 |
| 待下达 | 统一储备库 | 下达 | 已下达 |
| 已下达 | 统一储备库 | 查看 | — |

### 8.3 操作权限矩阵
